关于本系统

BookWMS 是一个面向图书仓储场景的演示型管理系统， 采用 Python Flask + SQLite 单体架构，适合作为毕业设计、课程作业或个人作品展示。

技术栈
  • 后端：Python 3.10 + Flask 3.0 + Flask-SQLAlchemy 3.1
  • 数据库：SQLite（单文件，零配置）
  • 前端：Bootstrap 5.3 + Bootstrap Icons + Jinja2 模板
  • 部署：Gunicorn + Render 免费版
  • 代码托管：GitHub（qty124/wms-demo）
功能模块
仪表盘（统计 + 预警 + 近期流水）
商品增删改查（搜索 + 分类筛选）
入库（自动累加 + 写流水）
出库（防负库存 + 写流水）
流水历史（按时间倒序）
库存预警（阈值可配置）
